# 🤖 ZENO 2.0 – Robô Inteligente com Python

## 📌 Sobre o projeto

O ZENO 2.0 é um robô virtual desenvolvido em Python, com interface gráfica, reconhecimento de comandos, inteligência artificial, animações e interação por voz.

O projeto combina técnicas de Machine Learning e Inteligência Artificial Generativa para proporcionar uma experiência de interação mais dinâmica com o usuário.

## 🚀 Funcionalidades

- **Interface gráfica:** desenvolvida com Tkinter.
- **Interação por voz:** permite que o robô fale com o usuário.
- **Reconhecimento de comandos:** identifica intenções por meio de frases digitadas.
- **Comando de ajuda:** apresenta opções de comandos disponíveis.
- **Respostas sobre Python:** responde à pergunta "O que é Python?".
- **Movimentação dos braços:** movimenta os dois braços ao receber o comando "dançar".
- **Estado feliz:** possui uma animação específica para representar felicidade.
- **Animações:** utiliza funções matemáticas para criar movimentos suaves.
- **Inteligência Artificial Generativa:** utiliza Ollama com o modelo Llama 3.2 para gerar respostas.

## 🧠 Tecnologias utilizadas

| Tecnologia | Finalidade |

## ⚙️ Funcionamento

O ZENO 2.0 utiliza Machine Learning para identificar a intenção do usuário a partir das frases digitadas.

O TfidfVectorizer transforma as frases em representações numéricas, enquanto o MLPClassifier identifica padrões e classifica as intenções.

Para conversas mais abertas, o projeto utiliza o Ollama com o modelo Llama 3.2, permitindo gerar respostas em linguagem natural.

A interface gráfica é responsável por apresentar o robô e suas animações, enquanto o threading permite executar tarefas sem bloquear a janela.
